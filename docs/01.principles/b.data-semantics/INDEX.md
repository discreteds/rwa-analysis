# Data semantics principles

| Principle | Status | Summary |
|---|---|---|
| [Layered, evidence-backed definitions](layered-metric-definitions.md) | AGREED | Definitions and contextual bindings cover all occurrence kinds; retain financial distinctions, field semantics/time, vintages, subset hierarchies and measure-specific scales. |
| [Correction-safe identity](correction-safe-identity.md) | AGREED | Identity and publication support changed interpretations, restatements and changed record grain. |
| [Format-independent target fields](format-independent-target-fields.md) | AGREED | Target fields are defined by meaning; template/format coordinates are source-side mappings; cross-format goldens prove convergence; regime changes use explicit field relationships. |
