# Architecture principles

| Principle | Status | Summary |
|---|---|---|
| [Contextual source occurrences](contextual-source-occurrences.md) | AGREED | Accepted 2026-10-13: physical sourcing, semantic meaning and extraction context bind every occurrence kind through singly owned, revisioned definitions. |
| [Metadata-driven extraction and conformance](metadata-driven-extraction-and-conformance.md) | AGREED | Accepted 2026-10-13: authoritative bindings govern extraction, retained Bronze and contextual Silver, superseding specified ownership clauses; replacement implementation is not implied. |
| [Capture and tag for research](capture-and-tag-for-research.md) | AGREED | Faithful capture and useful tagging support assumption-aware, approximate research without requiring perfect accounting. |
| [Complete capture across evolving disclosures](historical-disclosure-capture.md) | AGREED | Source-defined capture composes reusable definitions with distinct occurrences; query report structure over time while preserving changing semantics and absence. |
| [Evidence and interpretation](evidence-and-interpretation.md) | AGREED | Preserve source evidence and distinguish reported facts from interpretations and derivations. |
| [Multi-domain source bundles](multi-domain-source-bundles.md) | AGREED | One PDF owns a logical bundle; reviewed capture bindings can span domains, portfolios, periods and jurisdictions. |
| [Rebuildable analytical layers](rebuildable-analytical-layers.md) | AGREED | Durable inputs reproduce full Silver rebuilds; atomic publication does not imply a validation gate. |
| [Composed processing and organisation staging](composed-processing-and-organisation-staging.md) | AGREED | Metadata governs capture/conformance; technical declarations consume definitions and domain records are projections. Configuration/operations/workflow separation and normalised staging remain. |
| [Emergent analysis and selective persistence](emergent-analysis-and-selective-persistence.md) | AGREED | Persist durable knowledge; compute exploratory relationships on demand without embedding undefined validation in conformance. |
